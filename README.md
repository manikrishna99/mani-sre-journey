# SRE & Cloud Engineering Journey

A hands-on learning journey focused on Linux, Python automation, cloud infrastructure, DevOps practices, and Site Reliability Engineering.

## About This Repository

This repository documents my structured SRE and Cloud Engineering training through practical exercises, troubleshooting tasks, and progressively more realistic projects.

My goal is to develop the skills to build, automate, monitor, and troubleshoot reliable systems.
